# A 야간 튜닝·과보정 시각 검토 (#104)

## 목적과 범위

고정된 tuning 12장(일반 Clip_437, 어려움 Clip_230)에만 후보를 적용한다.
평가용 30장의 **메타데이터**는 중복 방지에만 사용하며 그 이미지·라벨은 열거나 처리하지 않는다.
원본·튜닝 CSV·라벨의 SHA-256을 고정 기록과 대조하고, 평가/튜닝 장면·원본·출력명 중복을 거부한다.
기존 FIXED_PARAMS는 변경하지 않는다. 이 단계는 시각 검토용이며 최종 튜닝 완료가 아니다.

```bash
python -m tools.review_night_tuning
```

기본 자료: `team_data/A_night/71588_night_highway_front`,
고정 목록: `data/manifests/a_night/`,
출력: `data/frames/tuning/night/review_v1/`.
기존 실험 폴더는 덮어쓰지 않는다. 재실험 시 `--output`에 새 경로를 지정한다.
출력은 원본 데이터·고정 목록과 겹치면 안 된다. 완료 표시 `REVIEW_READY.json`이 없으면
중간 실패한 자료이므로 사용하지 않는다. 이미지를 네트워크로 업로드하는 기능은 없다.

## 이번에 정한 실험 후보

모두 동일한 입력에 기존 NumPy `apply_ops`로 적용하며, 프레임별로 다른 후보를 고르지 않는다.

- **A**: 기존 고정값. Gaussian 3×3, σ1.0, gamma 0.75, hist_eq=False,
  Unsharp amount 0.8, σ1.0, threshold 5.
- **B**: A에서 Unsharp amount만 0.0. 샤프닝의 입자·테두리 증폭 영향을 분리해 본다.
- **C**: B에서 gamma만 0.60. 밝기 강화의 이득과 잡음·하이라이트 손실을 함께 확인한다.
- **D**: C에서 Gaussian을 5×5, σ1.2로 변경. 노이즈와 흐림 사이의 절충을 확인한다.

gamma 0.60, 5×5·σ1.2, 후보 구성은 구현자가 정한 **초기 비교 실험값**이다.
자동 탐색·최적값·품질 우위를 의미하지 않는다. histogram equalization은 모든 후보에서 끈다.
B/C/D가 더 빨라도 화질 우위가 입증되는 것은 아니다. 정보가 없는 검은 영역의 복원을 주장하지 않는다.

## 출력과 시각 검토 방법

- `index.html`: 로컬 브라우저에서 여는 오프라인 비교 페이지. 외부 CDN·fetch·폼 전송 없음.
  Original/A/B/C/D를 왼쪽·오른쪽에서 선택하고, 12장 모두 확인한다.
- 각 후보의 원본 크기 PNG와 `crops/`의 공통 영역 PNG. 원본 JPG를 디코딩한 픽셀을
  PNG로 보존하며 원본의 압축 손실을 복원했다고 표현하지 않는다.
- 크롭은 원본 라벨의 가장 넓은 차량에 폭·높이 15% 문맥을 더해 모든 후보에 똑같이 적용한다.
  차량 라벨이 없거나 유효하지 않으면 중앙 영역을 사용하고 그 사실을 기록한다.
  크롭은 검토용으로만 쓰며 평가 목록이나 OCR 크롭을 변경하지 않는다.
- `report.json`: 원본·출력·크롭 해시, 전체 params, 해상도, 진단값, 시간, 코드 버전.
- `feedback_template.txt`: 장면별 선호와 문제 프레임을 적는 양식.
- `REVIEW_READY.json`: 결과 상태는 `awaiting_human_review`, 평가 이미지 처리 수 0을 명시한다.

화면 밝기를 고정하고 먼저 전체 장면의 차량·차선 식별을 비교한다. 다음에 1:1 크롭에서
입자/얼룩, 색감 변화, 밝은 테두리(halo), 이중 윤곽, 글자·차선 흐림을 본다.
후보가 더 밝다는 이유만으로 고르지 않는다. 모두 부적합·차이 없음도 유효한 피드백이다.
복수 프레임의 일관성을 보고, 문제는 파일명 또는 페이지 순번과 후보를 함께 적는다.

예시(판정 예시일 뿐 추천 후보가 아님):

```text
일반 Clip_437: B 선호. A는 차량 가장자리에 밝은 테두리가 보임.
어려움 Clip_230: 모두 부적합. C/D는 밝아지지만 입자만 늘고 식별은 그대로임.
문제 프레임: 8번 / D / 도로가 얼룩져 보임.
```

## 지표·시간의 해석

mean Y, Y 표준편차, Y≤5·Y≥250 비율, 인접 Y 절대 차 평균을 설명용으로 기록한다.
인접 차이는 윤곽과 노이즈가 섞여 있어 노이즈 정답·선명도·화질 점수가 아니다.
정답 영상 없이 PSNR/SSIM을 만들거나 OCR 개선을 주장하지 않는다. 자동 우승 후보도 없다.

각 후보를 첫 튜닝 프레임에서 2회 워밍업한 뒤, 프레임당 한 번 적용해 시간을 기록한다.
이는 진단·디코딩·PNG 저장을 제외한 실험 호출 시간이며 반복 벤치마크와 다르다.
기존 고정 파이프라인 성능 목표 판정은 별도 반복 벤치마크를 사용한다.

## 최종 결정

사용자가 자료를 검토한 후 야간 후보를 좁힌다. 다른 조건의 튜닝 자료에서도 과노출·흐림·색감
문제가 없는지 확인하고 하나의 전역 고정값을 확정한다. 평가용 자료로 후보를 재선정하지 않는다.
최종값 변경은 별도 코드·테스트·결정 기록으로 남기고 모든 조건에 동일하게 적용한다.
이 실험 코드가 병합돼도 사용자의 시각 검토나 최종 고정값 확정이 완료된 것은 아니다.

원격 브라우저·외부 웹서비스에 이미지 업로드나 공개 터널을 사용하지 않는다.

서버 없이 index.html을 로컬 브라우저에서 직접 열어도 된다.

실험 생성 당시 상태는 사용자 시각 검토 대기였다. 위 수치로 최종 후보를 자동 선정하지 않았다.

### 가로줄에 대해 확인한 범위

합성된 균일 회색 16×16 입력(밝기 0~8)을 각 후보에 적용했다. 모든 결과는 공간적으로
균일했으며, 이 입력에서 줄무늬가 새로 생성되지는 않았다. 저명도 출력은 다음과 같았다.

- A/B: `0,4,7,9,11,13,15,17,19`
- C/D: `0,9,14,18,21,24,27,29,32`

gamma 0.60이 어두운 입력의 작은 차이를 더 크게 확대한다는 것은 수치로 확인했다.
그러나 이 실험만으로 실제 가로줄이 원본에서 확대된 것인지, 영상 계조·처리 과정에 따른
것인지 원인을 확정할 수 없다. 촬영 장치 문제나 특정 필터 버그로 단정하지 않는다.
원인 확정과 별개로 실제 튜닝 자료에서의 부정적 시각 피드백을 후보 제외 근거로 삼는다.

### 전역 고정값은 아직 미확정

일반 장면 B, 어려운 장면 A로 자동 전환하지 않는다. fixed는 모든 조건·프레임에 하나의
파라미터를 적용해야 한다. 다른 조건의 튜닝 자료에서 A/B를 비교한 뒤 최종값을 확정한다.
현재 소스의 FIXED_PARAMS는 **A 그대로 유지**하며, 이는 최종 튜닝 확정이 아니라 보류 상태다.
이번 기록 과정에서 평가 이미지 처리·새 후보 생성·원본 또는 frozen 실험 변경은 하지 않았다.
