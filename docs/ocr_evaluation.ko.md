# OCR 평가 (C-09)

[English](ocr_evaluation.md)

`eval_ocr(results, labels)`는 조건 하나를 채점합니다. `python -m src.eval.ocr`는
`results/ocr/<cond>.csv`를 모두 채점해 `results/ocr/ocr_summary.csv`를 씁니다.

## 번호판 라벨 형식

`data/labels/`의 JSON 파일에서 번호판 라벨을 읽습니다. 각 파일은 프레임 파일 이름과 그 프레임의 번호판 목록을 짝지어 둡니다.
B의 라벨 도구가 이 형식으로 씁니다. `python -m tools.b_labels export`가 다 채운 `data/annotations/scenes.json`을
`data/labels/plates.json`으로 바꿉니다.
`text: null`은 눈으로도 읽을 수 없는 번호판입니다. 번호판이 없는 프레임은 빈 목록입니다.

```json
{
  "fog_01_3500.png": [
    {"bbox": [412, 380, 96, 28], "text": "12가3456"},
    {"bbox": [120, 402, 40, 12], "text": null}
  ],
  "fog_01_7000.png": []
}
```

## 매칭

프레임마다 예측 번호판과 라벨 번호판을 1:1로 짝짓습니다. 두 박스가 겹친 넓이가 작은 박스의 절반 이상이면
(`overlap` ≥ 0.5) 짝이 될 수 있고, 그중 IoU가 큰 쌍부터 짝짓습니다. 그래서 크기가 가장 비슷한 박스가 짝이 됩니다.

전에는 IoU ≥ 0.5만 봤습니다. 샘플 10프레임으로 전체 흐름을 돌려 보니, 고정 보정 조건에서 번호판 4개가
원본과 같은 글자를 읽었는데도 박스가 더 좁거나 넓어서(IoU 0.07–0.32) 놓친 것으로 집계됐습니다.
그러면 검출률이 번호판을 찾았는지가 아니라 박스가 얼마나 딱 맞는지를 재게 됩니다.

## 지표

읽을 수 있는 표준 라벨 번호판(`text`가 null이 아니고 표준 번호판):

| 지표 | 정의 |
| --- | --- |
| `detection_rate` | 짝지어진 번호판 수 / 번호판 수 |
| `exact_match` | 짝지어졌고 라벨과 글자가 완전히 같은 번호판 수 / 번호판 수 |
| `char_accuracy` | max(0, 1 − 편집 거리 / 라벨 길이)의 평균. 놓쳤거나 글자가 없으면 0 |
| `readable_wrong` | 짝지어졌지만 readable로 판정되면서 글자가 틀린 번호판 수 |

읽을 수 없는 라벨 번호판은 위 비율에서 뺍니다.

| 지표 | 정의 |
| --- | --- |
| `unreadable_labels` | 개수 |
| `overconfident` | 그런데도 readable로 판정된 개수(지어낸 글자를 보여 주게 됨) |

표준 번호판이 아닌 라벨도 비율에서 뺍니다. 표준 번호판은 판정이 readable로 낼 수 있는 번호판입니다
([상태 판정 규칙](plate_recognition.ko.md)). 번호판 용도 문자만 쓰고, 앞에 지역명이 붙을 수 있습니다.
자동차 회사 광고용 번호판(123케4567, 12차3456), 군용, 외교 번호판은 실제로 있지만
절대 맞게 읽힐 수 없어서, 그대로 두면 항상 오답으로 잡힙니다.

| 지표 | 정의 |
| --- | --- |
| `nonstandard_labels` | 개수 |
| `readable_wrong` | 이런 번호판에 readable로 답한 경우도 셈 |

그 밖에 `frames`(라벨이 있는 프레임 수), `plates`, `missing_frames`(라벨은 있는데 CSV에 없는 프레임 수)도 냅니다.
읽을 수 있는 표준 라벨 번호판이 하나도 없으면 비율은 빈 값입니다.

`frame_char_accuracy(results, labels)`는 조건 비교(C-11)에 쓰도록 프레임별 평균 문자 정확도를 냅니다.
읽을 수 있는 표준 라벨 번호판이 없는 프레임은 `None`입니다.

## 손으로 확인한 경우

`tests/test_ocr_eval.py`에는 손으로 계산한 3가지 경우가 docstring에 정리되어 있습니다.
과신한 답 하나가 섞인 경우, 박스를 놓치고 글자를 틀린 경우, 1:1 매칭 경우입니다.
그 밖에 더 좁거나 넓은 박스, 크기가 가장 비슷한 박스가 짝이 되는 경우, 표준이 아닌 라벨도 테스트합니다.
